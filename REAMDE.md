  Brainiac Quiz Challenge
An interactive, fast-paced web trivia game built from scratch using HTML5, CSS3, and Vanilla JavaScript.
  Features
- 5 Diverse Categories:** General Knowledge, Video Games, Sports & Football, Science & Space, and Movies & TV.
- 20-Second Countdown Timer:** Dynamic timer per question with speed-based bonus points.
- Instant Feedback & Fun Facts:** Highlights correct/wrong answers immediately and reveals an interesting fact after every question.
- Progress Tracking & High Scores:** Visual progress bar and automatic high-score saving using browser `localStorage`.

 Built With
- HTML5
- CSS3 (Flexbox, Keyframe Animations)
- Vanilla JavaScript (DOM Manipulation, `localStorage`)
